## Описание задачи

Полный цикл разработки библиотеки «Калькулятор матриц» на C++17:

- **часть 1** — базовая библиотека: создание и освобождение матриц, сложение,
  умножение, транспонирование, вывод, создание из массива;
- **часть 2** — индивидуальное задание, **вариант 6**: функция
  `double matrix_average(Matrix m)`, которая вычисляет среднее арифметическое
  всех элементов матрицы;
- **часть 3** — модульные тесты (Google Test + CTest), проверка утечек памяти
  (Valgrind), документация (Doxygen), CI/CD (GitHub Actions), Docker.

## Сборка и запуск

Требования: CMake ≥ 3.20, компилятор с поддержкой C++17 (g++), для тестов
нужен доступ в интернет (Google Test скачивается при конфигурации).

```bash
cmake -B build
cmake --build build --parallel $(nproc)
./build/matrix_calculator          # демонстрация всех операций
./build/matrix_calculator -i       # интерактивный режим
cd build && ctest --verbose        # тесты
```

Проверка утечек памяти и документация:

```bash
valgrind --leak-check=full --error-exitcode=1 ./build/tests/matrix_tests
doxygen Doxyfile                   # результат: docs/html/index.html
```

Docker:

```bash
docker build -t matrix-calculator .
docker run --rm matrix-calculator                              # демо
docker run -it --rm matrix-calculator ./matrix_calculator -i   # ввод с клавиатуры
```

Форматирование кода (стиль задан в `.clang-format`):

```bash
find . -path ./build -prune -o \( -name '*.cpp' -o -name '*.h' \) -print | xargs clang-format -i
```

## Способ обработки ошибок

Во всём проекте используются **исключения**:

| Ситуация | Исключение |
|---|---|
| размеры матрицы `<= 0` | `std::invalid_argument` |
| несовпадение размеров при сложении, `cols(A) != rows(B)` при умножении | `std::invalid_argument` |
| пустая матрица / `data == nullptr` в операциях и в `matrix_average` | `std::invalid_argument` |
| `nullptr` вместо массива в `matrix_from_array` | `std::invalid_argument` |
| буквы вместо чисел, нехватка данных при вводе | `std::invalid_argument` |
| не удалось выделить память | `std::bad_alloc` |

`app::run` перехватывает все исключения, выводит сообщение в `stderr` и
возвращает код ошибки (1 — ошибка данных, 2 — неверные аргументы), поэтому
некорректный ввод не приводит к аварийному завершению.
`free_matrix` принимает матрицу по ссылке и обнуляет её, поэтому повторное
освобождение безопасно.

## Подзадачи и функции

| Подзадача | Функция | Модуль |
|---|---|---|
| Создание матрицы, заполненной нулями | `create_matrix(int rows, int cols)` | matrix |
| Освобождение памяти | `free_matrix(Matrix& m)` | matrix |
| Сложение | `matrix_add(Matrix a, Matrix b)` | matrix |
| Умножение (порядок циклов i-k-j) | `matrix_multiply(Matrix a, Matrix b)` | matrix |
| Транспонирование | `matrix_transpose(Matrix m)` | matrix |
| Вывод (в т. ч. сокращённый для больших матриц) | `print_matrix(Matrix m[, std::ostream&])` | matrix |
| Создание из одномерного массива | `matrix_from_array(const double*, int, int)` | matrix |
| Чтение матрицы из потока | `read_matrix(std::istream&)` | matrix |
| **Вариант 6: среднее арифметическое** | `matrix_average(Matrix m)` | matrix |
| Разбор аргументов командной строки | `app::parse_mode` | app |
| Демонстрация, интерактивный режим, справка | `app::run_demo`, `app::run_interactive`, `app::print_usage` | app |
| Запуск с перехватом исключений | `app::run` | app |

`matrix_average` сначала суммирует элементы обычным способом; если сумма
переполняет `double` (например, все элементы около `1e308`), среднее
пересчитывается как сумма `a[i][j] / (rows * cols)`, поэтому результат остаётся
конечным.

## Проверяемые сценарии (40 тестов)

- **Нормальные случаи:** создание матрицы 3x4 с нулями; сложение и умножение
  2x2; транспонирование 2x3; освобождение памяти; создание из массива по
  строкам; формат вывода; чтение из потока.
- **Граничные случаи:** матрица 1x1; вектор-строка x вектор-столбец = 1x1;
  двойное транспонирование; вывод пустой матрицы; сокращённый вывод 15x12;
  восстановление настроек потока.
- **Некорректные случаи:** нулевые и отрицательные размеры; сложение и
  умножение несовместимых матриц; повторное освобождение; операции с пустой
  матрицей; `nullptr` в `matrix_from_array`; буквы вместо чисел, нехватка
  данных и слишком большие размеры при вводе.
- **Вариант 6 (`matrix_average`):** типичный случай (2.5); отрицательные и
  дробные числа; матрица 1x1; нулевая матрица; вектор-строка и вектор-столбец;
  элементы около `DBL_MAX` без переполнения; пустая матрица, `nullptr`,
  отрицательный размер — исключение; среднее(A + B) = среднее(A) + среднее(B).
- **Приложение:** разбор ключей, интерактивный режим с корректным и
  некорректным вводом, полный прогон демонстрации, неизвестный ключ.

## Примеры входных и выходных данных

Интерактивный режим, корректный ввод:

```
$ printf '2 3\n1 2 3\n4 5 6\n' | ./build/matrix_calculator -i
Введите размеры матрицы (строки столбцы), затем элементы по строкам:
Матрица (2x3):
[    1.00    2.00    3.00 ]
[    4.00    5.00    6.00 ]
matrix_average(M) = 3.5
Транспонированная матрица (3x2):
[    1.00    4.00 ]
[    2.00    5.00 ]
[    3.00    6.00 ]
```

Некорректный ввод (буква вместо числа), код возврата 1:

```
$ printf '2 2\n1 x\n' | ./build/matrix_calculator -i
Введите размеры матрицы (строки столбцы), затем элементы по строкам:
Ошибка ввода: read_matrix: element [0][1] is not a number
```

Фрагмент демонстрационного режима (вариант 6):

```
A (2x2):
[    1.00    2.00 ]
[    3.00    4.00 ]
matrix_average(A) = 2.5
H (2x2) — все элементы равны 1e308, сумма переполняет double
matrix_average(H) = 1e+308
matrix_average(empty) -> исключение: matrix_average: matrix is empty or invalid
```

## CI/CD

При каждом `push` в `main`/`develop` и при pull request в `main` GitHub Actions:
проверяет стиль (clang-format 18), собирает проект, запускает тесты через
CTest, проверяет утечки памяти Valgrind (тесты и приложение), генерирует
документацию Doxygen и выгружает её как артефакт `documentation`, затем
собирает Docker-образ и запускает приложение в контейнере.
